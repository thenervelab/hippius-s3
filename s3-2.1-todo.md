## Architecture (current)

Node-local SSD ingest → CephFS pool via the Rust hippius-drain stack (`drain-allocator` singleton + `drain-agent`
DaemonSet). The API writes each part to node-local SSD + `object_versions.address`; it **never enqueues uploads**.
The **drain is the sole upload producer**: once a part replicates to the pool it LPUSHes an `UploadChainRequest` to
Redis; the uploader ships it to the storage backend and records `chunk_backend`. State machine:
`cephor_replication_status` = `pending → draining → replicated | failed` (terminal sinks). The janitor evicts a
CephFS part only once every required backend has a live `chunk_backend` row — or once the part is terminally abandoned.
Cross-node reads during the SSD→pool window are served by `DualFileSystemPartsStore` (pool fallback, no `chunk_backend`
row needed) in staging/prod. The cutover is **flagless** — the drain is the sole producer with no fallback, so every
availability item is live today.

**Priority note:** prod Postgres runs on dedicated NVMe; prod adds dedicated SSD nodes for ingest. So the PG-relief
track is churn-reduction (not a cliff), and SSD cleanup is required (a full SSD 503s every PUT on that node).

## R3 — the `write_allocations` lease-revalidation race (reclassify WI-18 "skip" → PROD GATE)

**Confirmed real, untested; the WI-18 "skip (marginal now redis is noeviction)" is wrong — the race is failover-timing,
independent of eviction.** `run_tick` (`tick.rs:77-83`) captures `epoch` at lease-acquire, then `load_fleet → ceiling()
(slow) → allocate → write_allocations(epoch)` with **no lease re-read**; the Lua fence only rejects against
already-written alloc keys. So a deposed A (epoch N) finishing a slow `ceiling()` before successor B (N+1) writes any
alloc key lands an epoch-N budget the fence lets through; an agent (2 s poll) enforces it, briefly exceeding B's ceiling.
**Every existing fence test seeds the higher epoch first, so this window is never exercised.**

**Fix (in robustness order):** (1) **register the epoch at the resource at election time, before any slow work** (bump a
resource watermark to N+1 the instant B wins — Chubby sequencer / etcd `mod_revision` pattern); (2) **fold the epoch into
the Lua CAS conditioned on current `cephor:epoch`/`cephor:leader`, not last written value** (reject any writer epoch below
current). A bare "re-read before write" is **insufficient** (irreducible check→write TOCTOU + the *lower* token reaching
the resource first — FizzBee/Jepsen formal results). **Test:** Rust `fail`/`failpoint` (or SIGSTOP) at the
`ceiling()`→`write_allocations` boundary; elect successor; release; **assert the successor's resource rejected A's write**
(assert the rejection, not "no corruption") — T4-C Tier-2 + the new T2-1 R3 case.
