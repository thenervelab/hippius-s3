## What's in the PR (largest first)

- **Data integrity** — the drain no longer deletes the SSD source unless the part is complete against `meta.json` *and* every chunk is byte-verified (bounded retry for transient torn writes); `mark_failed` is claim-fenced. Closes a silent-truncation edge.
- **Metrics → Grafana (the original release blocker)** — OTLP exporter (feature `otel`, default-on): `drain_parts_replicated_total`, `drain_ssd_backlog_bytes`, `drain_breaker_open` (agent) + `drain_leader`, `drain_fleet_estimate_bps` (allocator).
- **redis-queues → `noeviction`** — `allkeys-lru` could evict the epoch fence (→ allocator deadlock) *and* queued upload requests (→ silent lost uploads).
- **CI runs the coordination tier** — was silently skipping ~12 fencing/election/lease tests (green but testing nothing).
- **Liveness probes + non-zero exit on worker fault**; **breaker** `Probing`-deadline + non-Ceph-error carve-out; **Redis command timeouts** + decay-on-error; **batched reconciler**, **terminal-row GC**, **ancestor-dir fsync**; **backends-from-secret** + **schema-wait initContainer**.

Local gate on every commit: `fmt` + `clippy -D warnings` + full test suite (310 tests) with the coordination tier running.
